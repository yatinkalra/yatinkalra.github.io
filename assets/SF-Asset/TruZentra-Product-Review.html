Architecture
Key Design Principles
☁
FSC-First
Leverages FinServ__FinancialAccount__c, Transactions, and Card objects instead of custom objects for financial data.
✉
CMDT-Driven Emails
All 11 email types controlled via Zentra_Email_Config__mdt — toggle, branding, and content without code changes.
⚙
Invocable Apex + Flows
Every service is @InvocableMethod, wrapped by a Flow, invoked by the agent planner. Clean separation of concerns.
⚠
Centralized Logging
All exceptions routed to Zentra_Error_Log__c. All emails audited in Zentra_Email_Log__c. Full observability.
🔒
OTP-Gated Security
Every sensitive action gated behind OTP. Role-based permission sets. Full audit trail for emails and errors.
🌐
Auto-Detect Multilingual
English, Hindi, Hinglish — auto-detected per message. Every service formats output in the customer's language.

Security First

Bank-Grade OTP Authentication & Access Control

Every sensitive action is gated behind OTP verification. The verified customer identity is securely propagated across all 9 agent topics via variable mapping — making cross-customer data leaks impossible. Full audit trails log every email sent and every error encountered.

Multilingual Intelligence

Speaks Your Customer's Language — Automatically

TruZentra auto-detects the customer's language from their very first message and responds naturally — whether they type in formal English, Hindi (Devanagari), or Hinglish (Roman Hindi). Every Apex service formats its output in the detected language. No configuration needed.
